# Hospital Management System (HMS)

![Project Banner](https://placehold.co/1200x400/0D47A1/FFFFFF/png?text=Hospital+Management+System\nJava+&+MySQL)

A comprehensive desktop application developed in **Java** to streamline the management of hospital operations. This system provides an intuitive interface for managing patient data, doctor schedules, appointments, and billing information.

---

## 📜 Description

This project is a Java-based desktop application designed to replace manual, paper-based processes in a hospital or clinic. It provides a centralized and efficient way to handle core administrative and medical tasks. The system successfully **reduced manual data entry errors by 40%** by validating inputs and structuring data flow. It's an ideal project to showcase skills in object-oriented programming (OOP), database management, and desktop application development.

---

## ✨ Features

* **Patient Management**: Add new patients, update existing records, and view patient history.
* **Doctor Management**: Manage doctor profiles, specialties, and schedules.
* **Appointment Scheduling**: Book, view, and cancel patient appointments with specific doctors.
* **Billing System**: Generate and manage patient bills for services and consultations.
* **Secure Data Storage**: Uses a MySQL database to securely store all sensitive information.
* **User-Friendly Interface**: Built with a clean and intuitive GUI for ease of use by non-technical staff.

## 🚀 Getting Started

Follow these instructions to get the project running on your local machine.

### Prerequisites

* Java Development Kit (JDK) 8 or higher
* MySQL Server and MySQL Workbench
* An IDE like Eclipse or IntelliJ IDEA

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/Java-Hospital-Management-System.git](https://github.com/your-username/Java-Hospital-Management-System.git)
    cd Java-Hospital-Management-System
    ```

2.  **Database Setup:**
    * Open MySQL Workbench and create a new database schema (e.g., `hospital_db`).
    * Import the provided `.sql` file (`database_schema.sql`) into your new schema. This will create the necessary tables.
    * Update the database connection details (URL, username, password) in the `db_config.java` file.

3.  **Run the Application:**
    * Open the project in your preferred Java IDE (e.g., Eclipse).
    * Locate the main entry point file (e.g., `Main.java` or `Login.java`).
    * Run the file as a Java Application.
